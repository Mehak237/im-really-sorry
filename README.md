# 🧸 "I'm Really Sorry" — Interactive Personal Apology Experience 💗

A romantic, emotional, animated apology surprise website built with React and Tailwind CSS. Designed to feel like a heartfelt handmade gift with interactive storytelling, memories scrapbook, realistic letters, voice recording, playful interactions, and customizable content.

---

## ✨ Features & Journey

1. **Opening Screen — A Cute Surprise**
   - Soft pastel pink, lavender, and baby blue gradient.
   - Floating hearts, stars, butterflies, and gentle sparkles.
   - Cute animated teddy bear holding a beating heart with sparkling eyes and rosy cheeks.
   - Sincere opening: *"Hey You... 🥺"* — *"I made something special for you. Will you give me a minute?"*
   - Interactive button: *"Open My Little Surprise 💗"*.

2. **The Sorry Screen**
   - Cute animated crying teddy bear with streaming tears and a bandaged broken heart.
   - Heartfelt apology note on a polaroid scrapbook card with washi tape.
   - Animated *"I'm Really Sorry... 🥺 💗"* button with romantic chimes.

3. **Interactive Yes / No Screen**
   - Heading: *"Can You Forgive Me? 🥺"*
   - **YES, I Forgive You 💗**: Triggers a dual-cannon romantic confetti explosion.
   - **NO 😤**: Playfully dodges and moves away when hovered or touched with cute reactions (*"Wait please! 🥺"*, *"Are you sure? 🥺"*, *"My heart says YES! 💗"*), keeping the experience lighthearted and sweet without blocking them.

4. **Our Memories Gallery**
   - Polaroid scrapbook photo cards with washi tape, tilt angles, shadows, and hover animations.
   - Customizable dates, titles, and descriptions.
   - Full-screen lightbox view when clicking any photo.
   - Chapter timeline showing special milestones.
   - Live photo upload directly from phone or desktop!

5. **Three Personal Letters**
   - **Letter 1:** *"Things I Never Said 💌"* — A heartfelt message about how much they mean to you.
   - **Letter 2:** *"If I Could Go Back... ⏳"* — Genuine regret, taking accountability, and wishing to handle things with gentleness.
   - **Letter 3:** *"A Promise From My Heart ❤️"* — Sincere commitment to communicate better and learn from mistakes.
   - Realistic envelope opening and handwritten calligraphy (`Caveat` cursive font) with a *"Close Letter"* button.

6. **Voice Message Section**
   - Heading: *"One Last Thing... 💭"*
   - Animated retro cassette tape player with rotating reels.
   - Built-in microphone voice recorder (record directly from your phone/laptop!) or audio file uploader.
   - Customizable sweet message card.

7. **Final Forgiveness Screen**
   - Teddy bear holding a giant blooming heart.
   - Heading: *"So... Can We Start Again? 🥺"*
   - Two compassionate choices:
     - **"I Forgive You 💗"**: Shows confetti celebration and: *"YAY! Thank you for giving me a chance. I'll try to make things better. ❤️"*
     - **"I Need Some Time 🤍"**: Shows loving, respectful message: *"That's okay. Take all the time you need. I respect your feelings. 🤍"*

8. **Design & Audio**
   - Gentle lullaby / music-box background music powered by the Web Audio API (zero broken audio links).
   - Visible mute/unmute control in the top bar. Music does not autoplay (respecting modern web guidelines).
   - Fairy dust heart cursor on desktop.
   - Stepper progress pills to navigate easily.

9. **Live Customizer & Shareable Link**
   - Click **"⚙️ Customize"** in the top bar to:
     - Change recipient name (e.g., *"My Sweetheart"*, *"Sarah"*).
     - Change your name.
     - Edit all 3 letter contents live.
     - Upload your own pictures with captions and dates.
     - Attach your own voice note.
     - Edit apology and final messages.
   - Click **"🔗 Copy Shareable Link For Recipient"** to generate an encoded URL with all your changes. Send the link to the recipient; they will see your exact personalized version with **no login required**!

## 🚀 How to Run

### Method 1: Instant Standalone (No Node/Build required)
Double-click `index.html` inside `d:\claude\im-really-sorry\index.html` or open it with Google Chrome, Microsoft Edge, Safari, or on your smartphone!

### Method 2: Modern Vite Dev Server (React)
Open PowerShell in `d:\claude\im-really-sorry`:

```powershell
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

## 🌐 Free 1-Minute Hosting & Sharing

To send this as a live website link to someone:

### Option A: Netlify Drop (Easiest - 30 seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the `d:\claude\im-really-sorry` folder (or just `index.html`).
3. Netlify will generate an instant public URL (e.g. `https://im-really-sorry-for-you.netlify.app`)!

### Option B: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings** > **Pages** > Set source to `main` branch.
3. Your site is live!
